Описание API публичного сервиса ФНС России «Proxy-копия единого классификатора полномочий для МЧД из ЕСНСИ ФГИС ЕСИА»

## Общие положения

-  Сервис предоставляет возможность интеграции с корпоративными информационными системами и сторонними программными решениями для автоматического получения из ЕСНСИ ФГИС «ЕСИА» записей Единого классификатора полномочий для МЧД.
-  Для взаимодействия с сервисом используется REST API - стандартный протокол для обмена данными между информационными системами.
-  В JSON-ответах, предоставляемых в стандартном машиночитаемом формате, структура данных строго определена и не изменяется в рамках одной версии API.
-  Эндпоинт сервиса расположен по адресу:

https://kpmp.nalog.gov.ru/authority-classifier-idmz/api/v1/GetAllRecords

## Публичный сервис ФНС России «Proxy-копия единого классификатора полномочий для МЧД из ЕСНСИ ФГИС ЕСИА»

Запрос

GET https://kpmp.nalog.gov.ru/authority-classifier-idmz/api/v1/GetAllRecords

Возвращает текущий набор записей справочника (по состоянию на текущую дату и время сервера ФНС России (МСК)).

Параметры:

- 'date' (необязательный) - Возвращает набор записей справочника, по состоянию на указанную дату в запросе.

Поддерживаемые форматы параметра 'date':

- 'yyyy-MM-dd' - дата без времени
- 'yyyy-MM-ddTHH:mm' - дата с часами и минутами
- 'yyyy-MM-ddTHH:mm:ss' - дата с точностью до секунд
- 'yyyy-MM-ddTHH:mm:ss.sss' - дата с миллисекундами
- 'yyyy-MM-ddTHH:mm:ss.sssZ' - дата в формате UTC

Примеры запросов:

- Справочник актуален на текущую дату по МСК:

GET https://kpmp.nalog.gov.ru/authority-classifier-idmz/api/v1/GetAllRecords

GET https://kpmp.nalog.gov.ru/authority-classifier-idmz/api/v1/GetAllRecords

- Справочник актуален на 15 ноября 2025 года: ?date=2025-11-15
- Справочник актуален на 15 ноября 2025 года 14:30:

GET https://kpmp.nalog.gov.ru/authority-classifier-idmz/api/v1/GetAllRecords

?date=2025-11-15T14:30

## - Справочник актуален на 15 ноября 2025 года 14:30:00:

GET https://kpmp.nalog.gov.ru/authority-classifier-idmz/api/v1/GetAllRecords ?date=2025-11-15T14:30:00

- Справочник актуален на 15 ноября 2025 года 14:30:00.000: GET https://kpmp.nalog.gov.ru/authority-classifier-idmz/api/v1/GetAllRecords ?date=2025-11-15T14:30:00.000
