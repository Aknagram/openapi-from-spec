GET accountBalances?accounts=acc1&accounts=acc2
Метод запроса текущего остатка по счетам

Описание
Данный метод позволяет запросить информацию о текущем остатке средств на одном или нескольких счетах.
Поддерживается одновременный запрос баланса для нескольких счетов через список идентификаторов.

Параметры запроса

Параметр	Тип данных	Максимальная длина	Обязательность	Описание
accounts	List	64	Да	Список идентификаторов счетов

Параметры ответа

Парамет	Тип данных	Максимальная длина	Описание
balances	Array		Массив объектов с балансами
└─ account	String	64	Идентификатор счета
└─ maskedNumber	String	20	Частично скрытый номер счета
└─ balanceAmount	Long	18	Текущий остаток на счете
totalBalance	Long	18	Суммарный остаток по всем счетам

Пример ответа
JSON

{
  "balances": [
    {
      "account": "A1B2C3D4E5F6789012345678",
      "maskedNumber": "****1234",
      "balanceAmount": 1500000000
    },
    {
      "account": "X9Y8Z7W6V5U4T3S2R1Q0P9O8",
      "maskedNumber": "****5678",
      "balanceAmount": 3200000000
    }
  ],
  "totalBalance": 4700000000
}
