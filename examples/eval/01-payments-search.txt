GET paymentsSearch?status=NEW&active=true

Метод поиска платежей

Описание
Возвращает список платежей за период.

Параметры запроса

Параметр	Тип данных	Максимальная длина	Обязательность	Описание
dateFrom	Date		Нет	Начало периода
dateTo	Date		Нет	Конец периода
active	Boolean		Нет	Только активные платежи
limit	Integer	4	Нет	Размер страницы
status	String	16	Да	Статус платежа

Параметры ответа

Параметр	Тип данных	Максимальная длина	Описание
payments	Array		Список платежей
└─ paymentId	String	36	Идентификатор платежа
└─ amount	Long	12	Сумма в минимальных единицах
total	Integer	8	Число найденных платежей

Пример ответа
JSON

{
  "payments": [
    {
      "paymentId": "pay-100",
      "amount": 2500
    }
  ],
  "total": 1
}
