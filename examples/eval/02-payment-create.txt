Создание платежа paymentCreate

Описание
Создаёт платёж между счетами клиента.

Тело запроса

Параметр	Тип данных	Максимальная длина	Обязательность	Описание
amount	Long	12	Да	Сумма
currency	String	3	Да	Код валюты
comment	String	140	Нет	Назначение платежа

Параметры ответа

Параметр	Тип данных	Максимальная длина	Описание
paymentId	UUID		Идентификатор созданного платежа
acceptedAt	DateTime		Момент принятия платежа
