GET /cards/{cardId}

Метод карточки

Описание
Возвращает карточку по идентификатору.

Параметры пути

Параметр	Тип данных	Обязательность	Описание
cardId	String	Да	Идентификатор карты

Заголовки

Параметр	Тип данных	Обязательность	Описание
X-Request-Id	UUID	Нет	Идентификатор запроса

Параметры ответа

Параметр	Тип данных	Максимальная длина	Описание
maskedPan	String	20	Маскированный номер карты
expiresOn	Date		Срок действия
active	Boolean		Карта действует
