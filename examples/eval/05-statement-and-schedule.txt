GET accountStatement

Метод выписки

Описание
Возвращает выписку по счёту.

Параметры запроса

Параметр	Тип данных	Максимальная длина	Обязательность	Описание
account	String	20	Да	Номер счёта

Параметры ответа

Параметр	Тип данных	Максимальная длина	Описание
entries	Array		Проводки по счёту
└─ postedAt	DateTime		Дата проводки
└─ amount	Long	15	Сумма проводки

DELETE statementSchedule

Удаление расписания выписки

Описание
Удаляет расписание регулярной выписки.

Параметры запроса

Параметр	Тип данных	Максимальная длина	Обязательность	Описание
scheduleId	String	36	Да	Идентификатор расписания
