GET invoiceFlags

Описание
Возвращает флаги счёта.

Параметры запроса

Параметр	Тип данных	Максимальная длина	Обязательность	Описание
showClosed	Boolean		M	Показывать закрытые счета
withDrafts	Boolean		O	Включать черновики
ownerId	String	36	O	Владелец счёта
region	String	8		Регион обслуживания
note	String	20	О	Примечание к флагу
