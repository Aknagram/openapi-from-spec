GET notifications?ids=n1&ids=n2

Описание
Возвращает уведомления по списку идентификаторов.

Параметры запроса

Параметр	Тип данных	Максимальная длина	Обязательность	Описание
ids	List	64	Да	Идентификаторы уведомлений

Параметры ответа

Параметр	Тип данных	Максимальная длина	Описание
items	Array		Уведомления
└─ id	String	64	Идентификатор
└─ read	Boolean		Признак прочтения
