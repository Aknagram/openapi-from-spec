PUT catalogItem

Описание
Сохраняет карточку товара в каталоге.

Тело запроса

Параметр	Тип данных	Максимальная длина	Обязательность	Описание
sku	String	32	Да	Артикул
price	Number		Да	Цена
weight	Decimal		Нет	Вес
discount	Float		Нет	Скидка
photo	File		Нет	Изображение товара
visible	Boolean		Да	Признак публикации

Параметры ответа

Параметр	Тип данных	Максимальная длина	Описание
version	Integer	8	Версия карточки
