GET ordersSearch?status=NEW&active=true

Метод поиска заказов

Описание
Возвращает список заказов клиента за период.

Параметры запроса

Параметр	Тип данных	Максимальная длина	Обязательность	Описание
customerId	String	36	Да	Идентификатор клиента
dateFrom	Date		Нет	Начало периода
dateTo	Date		Нет	Конец периода
status	String	16	Нет	Статус заказа
active	Boolean		Нет	Только незакрытые заказы
limit	Integer	4	Нет	Размер страницы

Параметры ответа

Параметр	Тип данных	Максимальная длина	Описание
orders	Array		Список заказов
└─ orderId	UUID		Идентификатор заказа
└─ status	String	16	Статус заказа
└─ totalAmount	Long	12	Сумма заказа в минимальных единицах
total	Integer	8	Число найденных заказов

Пример ответа
JSON

{
  "orders": [
    {
      "orderId": "6f1c0a2e-4b7d-4e1a-9c33-2a1b0c9d8e77",
      "status": "NEW",
      "totalAmount": 259000
    }
  ],
  "total": 1
}

GET /orders/{orderId}

Метод заказа

Описание
Возвращает заказ по идентификатору вместе с позициями.

Параметры пути

Параметр	Тип данных	Обязательность	Описание
orderId	UUID	Да	Идентификатор заказа

Заголовки

Параметр	Тип данных	Обязательность	Описание
X-Request-Id	UUID	Нет	Идентификатор запроса

Параметры ответа

Параметр	Тип данных	Максимальная длина	Описание
orderId	UUID		Идентификатор заказа
status	String	16	Статус заказа
createdAt	DateTime		Момент создания
items	Array		Позиции заказа
└─ sku	String	32	Артикул товара
└─ name	String	120	Название товара
└─ quantity	Integer	4	Количество
└─ price	Long	12	Цена единицы в минимальных единицах
totalAmount	Long	12	Сумма заказа в минимальных единицах

POST ordersCreate

Создание заказа

Описание
Создаёт заказ по списку позиций.

Тело запроса

Параметр	Тип данных	Максимальная длина	Обязательность	Описание
customerId	String	36	Да	Идентификатор клиента
comment	String	200	Нет	Комментарий к заказу
items	Array		Да	Позиции заказа
└─ sku	String	32	Да	Артикул товара
└─ quantity	Integer	4	Да	Количество

Параметры ответа

Параметр	Тип данных	Максимальная длина	Описание
orderId	UUID		Идентификатор созданного заказа
status	String	16	Статус заказа
acceptedAt	DateTime		Момент принятия заказа

PATCH /orders/{orderId}

Изменение статуса заказа

Описание
Меняет статус существующего заказа.

Параметры пути

Параметр	Тип данных	Обязательность	Описание
orderId	UUID	Да	Идентификатор заказа

Тело запроса

Параметр	Тип данных	Максимальная длина	Обязательность	Описание
status	String	16	Да	Новый статус
changedAt	DateTime		Нет	Момент изменения

Параметры ответа

Параметр	Тип данных	Максимальная длина	Описание
orderId	UUID		Идентификатор заказа
status	String	16	Статус после изменения

DELETE ordersCancel

Отмена заказа

Описание
Отменяет заказ, если он ещё не передан в доставку.

Параметры запроса

Параметр	Тип данных	Максимальная длина	Обязательность	Описание
orderId	UUID		Да	Идентификатор заказа
reason	String	200	Нет	Причина отмены

Параметры ответа

Параметр	Тип данных	Максимальная длина	Описание
orderId	UUID		Идентификатор заказа
cancelled	Boolean		Признак отмены
