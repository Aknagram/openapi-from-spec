# Служба курьерских заказов

Разрешенные запросы: GET, POST, PUT, DELETE

## Список заказов

GET /courier/orders

Возвращает заказы, назначенные текущему курьеру.

| Наименование | Обозначение | Формат | Обязательность | Примечание |
| --- | --- | --- | --- | --- |
| orderId | Номер заказа | string | Да | |
| address | Адрес доставки | string | Да | |
| weightKg | Масса отправления | number | Нет | |

Пример ответа (200 OK)

```json
{"orders":[{"orderId":"A-17","address":"Невский 10","weightKg":1.5}]}
```

## Новый заказ

POST /courier/orders

Создаёт заказ и возвращает его номер.

| Наименование | Обозначение | Формат | Обязательность |
| --- | --- | --- | --- |
| address | Адрес доставки | string | Да |
| weightKg | Масса отправления | number | Нет |

Пример запроса:

```json
{"address":"Невский 10","weightKg":null}
```

Пример ответа (201 Created)

```json
{"orderId":"A-18"}
```
