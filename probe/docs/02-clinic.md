# Запись к врачу

Базовый адрес сервиса задаётся плейсхолдером {apiUrl}.

| Тип запроса | Наименование метода | URL | Синхронность |
| --- | --- | --- | --- |
| GET | listSlots | {apiUrl}/clinic/slots | Да |
| POST | bookSlot | {apiUrl}/clinic/slots | Да |

GET {apiUrl}/clinic/slots?doctorId=card-12

Параметр doctorId обязателен и задаёт врача.

POST {apiUrl}/clinic/slots

Тело записи:

| Наименование | Обозначение | Формат | Обязательность |
| --- | --- | --- | --- |
| doctorId | Врач | string | Да |
| day | День приёма | string | Да |

```json
{"doctorId":"card-12","day":"2026-04-01"}
```

## Коды ответа

Сервис использует следующие HTTP-коды.

| Код ответа | Описание |
| --- | --- |
| 200 | Слоты возвращены |
| 400 | Неверная дата приёма |
| 403 | Нет права на запись |
| 503 | Регистратура недоступна |
