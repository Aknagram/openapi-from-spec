# Показания приборов учёта

curl -X GET "<https://grid.example/meters/v2/readings?account=100>"

Возвращает показания лицевого счёта.

Параметр date необязательный. Поддерживаемые форматы параметра 'date':

- 'yyyy-MM-dd' — дата без времени
- 'yyyy-MM-ddTHH:mm:ssZ' — дата со временем в UTC

## Формат ответа

| Наименование | Обозначение | Формат | Обязательность |
| --- | --- | --- | --- |
| reading | Показание счётчика | Reading | Да |

## Список атрибутов reading

| Наименование | Обозначение | Формат | Обязательность |
| --- | --- | --- | --- |
| value | Значение | number | Да |
| takenAt | Момент снятия | string | Да |

Пример ответа:

```json
{"readings":[{"value":42,"takenAt":"2026-01-02T03:04:05Z"}]}
```

## 409 Conflict - показание за эту дату уже принято.

```json
{"messageToUser":"Показание уже есть"}
```
