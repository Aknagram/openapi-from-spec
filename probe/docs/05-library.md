# Выдача книг

POST /library/loans

Оформляет выдачу книги читателю.

Для запроса

| Наименование | Обозначение | Формат | Обязательность |
| --- | --- | --- | --- |
| readerId | Читательский билет | string | Да |
| bookId | Инвентарный номер | string | Да |

Пример некорректного запроса:

```json
{"readerId":""}
```

Пример запроса:

```json
{"readerId":"r-1","bookId":"b-9"}
```

Для тела ответа

| Наименование | Обозначение | Формат | Обязательность |
| --- | --- | --- | --- |
| loanId | Номер выдачи | string | Да |
| bookId | Инвентарный номер | string | Да |

Пример ответа (201 Created)

```json
{"loanId":"L-3","bookId":"b-9"}
```

## Книга не выдаётся

У читателя есть задолженность, поэтому выдачу отклоняют.

Код HTTP: 422

```json
{"errorMessage":"У читателя есть задолженность"}
```
