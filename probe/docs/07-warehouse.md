PATCH /warehouse/moves/{moveId}

Меняет склад назначения у уже созданного перемещения.

| Наименование | Обозначение | Формат | Обязательность |
| --- | --- | --- | --- |
| comment | Комментарий кладовщика | string | Нет |
| destination | Склад назначения | string | Да |

Пример запроса:

```json
{"comment":null,"destination":"Север"}
```

Пример ответа (200 OK)

```json
{"moveId":"m-1","destination":"Север","comment":null}
```
