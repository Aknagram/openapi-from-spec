# Возврат билетов

POST https://tickets.example/sales/refunds

Принимает заявление на возврат билета.

| Наименование | Обозначение | Формат | Обязательность |
| --- | --- | --- | --- |
| ticket | Номер билета | string | Да |
| reason | Причина возврата | string | Да |

Пример запроса:

```json
{"ticket":"T-100","reason":"болезнь"}
```

400 Bad Request - дата сеанса уже прошла. Тело ответа пустое.

## 422 Unprocessable Entity - заявление уже подано.

```json
{"errorMessage":"Возврат уже оформлен"}
```
