# Архив документов

#### 1 шаг. Описываем конечную точку

Для примера я указываем только чтение карточки, логичнее было бы описать и поиск.

GET /archive/cards/{cardId}

Возвращает карточку документа по её номеру.

| Наименование | Обозначение | Формат | Обязательность |
| --- | --- | --- | --- |
| title | Заголовок карточки | string | Да |

Пример ответа (200 OK)

```json
{"title":"Договор поставки"}
```

#### 2 шаг.

curl -X DELETE '<https://archive.example/archive/cards/15>'

Удаляет карточку без тела ответа.
