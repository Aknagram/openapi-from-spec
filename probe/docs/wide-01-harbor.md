v 4.2

## 1. registerCall — регистрация захода

Метод создаёт карточку захода. Отдельных query-полей нет.

POST {apiUrl}/harbor/v1/calls

### Для запроса

| Наименование | Обозначение | Формат | Обязательность |
| --- | --- | --- | --- |
| vesselName | Название судна | string | Да |
| imo | Номер IMO | string | Да |

### Для тела ответа

| Наименование | Обозначение | Формат | Обязательность |
| --- | --- | --- | --- |
| callId | Идентификатор захода | string | Да |
| berthSeal | Печать причала | string | Да |

### Коды ответа

| Код | Пояснение |
| --- | --- |
| 201 | Карточка создана |
| 409 | Причал занят |

Пример ответа 409:

{ "error": "Причал занят" }
