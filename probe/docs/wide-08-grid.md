Адрес содержит только path. Прочие входы названы в конце метода.

GET {apiUrl}/grid/v1/meters/{meterId}/readings

### Для запроса

| Наименование | Расположение | Формат | Обязательность |
| --- | --- | --- | --- |
| meterId | Path | string | Да |
| meterPoint | Query | string | Нет |
| X-Trace | Header | string | Да |

### Для тела ответа

| Наименование | Обозначение | Формат | Обязательность |
| --- | --- | --- | --- |
| readings | Показания | array | Да |
| readingSeal | Печать показания | string | Да |

Элемент массива readings:

| Наименование | Обозначение | Формат | Обязательность |
| --- | --- | --- | --- |
| valueKw | Значение, кВт | number | Да |
| takenAt | Момент снятия | string | Да |

### Коды ответа

| Код | Пояснение |
| --- | --- |
| 200 | Показания |
