### Для запроса

| Наименование | Обозначение | Формат | Обязательность |
| --- | --- | --- | --- |
| complaint | Жалоба | string | Да |

### Для тела ответа

| Наименование | Обозначение | Формат | Обязательность |
| --- | --- | --- | --- |
| visitId | Идентификатор визита | string | Да |
| patient | Пациент | object | Да |
| patient.policyNumber | Номер полиса | string | Да |
| protocolStamp | Печать протокола | string | Да |

### Коды ответа

| Код | Пояснение |
| --- | --- |
| 201 | Протокол создан |
| 400 | Тело ответа пустое |
| 422 | Протокол уже подписан |

Пример ответа 422:

{ "error": "Протокол уже подписан" }
